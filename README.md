# Quiz Application

A simple Python Quiz Application built using a menu-driven interface.

## Features

- Start Quiz
- Multiple Choice Questions
- Automatic Score Calculation
- View Last Score
- Percentage Calculation
- Exit Program

## Concepts Used

- Functions
- Conditional Statements
- Loops
- Variables
- User Input Handling
- Score Tracking

## Menu

1. Start Quiz
2. View Score
3. Exit

## Sample Questions

- What is the capital of India?
- Which keyword is used to create a function in Python?
- Which data type uses square brackets []?
- What is the output of print(5 + 3)?
- Which loop is used to repeat code multiple times?

## Technologies Used

This project was created to practice Python programming concepts such as functions, conditions, loops, and user interaction through a quiz-based application.
